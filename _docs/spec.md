# yard について

yard はツール群をイントラ内で公開する為のプロキシサーバです。
Webサーバとして作成したツールはそれぞれポートを別にして起動したり、サービス化したりしなければいけません。
それを解消する為、yardを利用します。

既存のプロキシサーバなどの利用することも考えましたが、
このアプリではプログラムの実行もこのサーバで行うという特徴があります。

## 設定ファイル

yard.ini で TOML で管理されます。

起動するプログラムを指定して、URIを指定できるようにします。
指定されたURIに対して、起動しているプログラムのサーバにリダイレクトする

起動するプログラムの標準出力は基本的に無視するが、設定がある場合ファイルに出力する。
またアクセスログも残せるようにはしておく。

## 特殊URL

「/.yard」がアプリURLになり、設定、生死確認などを行うことができます。

## 指定するツールについて

起動する時にポートやBASEを設定できること
※このアプリで考えるものではない

yard 上で端末の空いているポートを取得し、ツールの起動ポートに指定して起動します。
そのためプログラムを実行する時、引数を指定できるようにしておく必要があります。

## サービス化を行う
 
github.com/kardianos/service を利用してサービス化を行えるようにする
※他OSでの挙動も調べる
